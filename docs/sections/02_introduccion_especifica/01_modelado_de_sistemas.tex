\subsection{Modelado de sistemas}
\label{sec:modelado_de_sistemas}
Dentro del aprendizaje automático, existen dos enfoques principales:

\begin{itemize}
    \item Aprendizaje supervisado: en este enfoque, el modelo se entrena mediante un conjunto de datos etiquetados, donde cada entrada tiene una salida correspondiente conocida. El objetivo es que el modelo aprenda a mapear las entradas a las salidas correctas.
    \item Aprendizaje no supervisado: en este enfoque, el modelo se entrena mediante datos no etiquetados. El objetivo es que el modelo descubra patrones o estructuras subyacentes en los datos sin la guía de salidas conocidas.
\end{itemize}

Este trabajo se enfoca en el aprendizaje supervisado, en el que pueden distinguirse principalmente dos tipos de problemas: los de regresión y los de clasificación.

En los problemas de regresión, el objetivo consiste en predecir una variable de salida continua a partir de un conjunto de variables de entrada, mientras que en los problemas de clasificación la salida es discreta o categórica, y representa la pertenencia de una observación $x_j$ a una clase o categoría determinada. Ambos enfoques comparten el mismo principio general de aprendizaje a partir conjunto de datos etiquetados $\mathcal{D} = \{(x_i,y_i)\}_{i=1}^N$, donde cada par $(x_i,y_i)$ representa un valor de entrada y su correspondiente salida para un sistema cuya relación funcional es desconocida $y = f(x)$, tal como se muestra en la \reffig{system}.

        \node[rectangle, draw, minimum width=2cm, minimum height=1cm, right=of input] (system) {$f$};
        \node (output) [right=of system] {$y$};

Un modelo en este contexto busca establecer una relación funcional entre las variables de entrada $x$ y la salida $y$, de manera que sea capaz de generalizar el comportamiento observado en los datos. Dicha relación puede expresarse mediante una función $\hat{f}(x;\theta)$, donde $\theta$ representa el conjunto de parámetros del modelo. Esta relación se representa en \eqref{eq:system_approximation}.

\begin{equation}
    \label{eq:system_approximation}
    \hat{y} = \hat{f}(x; \theta) \approx f(x)
\end{equation}

En la práctica, los datos disponibles suelen contener ruido, ya sea en las variables de entrada, en la salida o en ambas. Este ruido puede provenir de errores de medición, incertidumbre inherente al sistema o factores no observados que afectan la variable objetivo. Por esta razón, el modelo no busca reproducir exactamente las observaciones, sino aproximar la relación subyacente entre las variables que generaron dichos datos \cite{Bishop2006}. En la \reffig{system_noise} se muestra un esquema donde la salida $y$ tiene una componente de ruido aditivo.

        \node[circle, draw, minimum size=0.8cm, right=of output] (add) {$+$};
        \node (final_output) [right=of add] {$y$};
        \node (noise) [below=of add] {$n$};

    \end{tikzpicture}
    \caption{Sistema observado con ruido.}
    \label{fig:system_noise}
\end{figure}

El objetivo del aprendizaje supervisado es aproximar la función desconocida $f$ a partir de un conjunto de datos con ruido, de modo que la función estimada $\hat{f}(x; \theta)$ se acerque lo más posible a $f$ bajo algún criterio de error o desempeño.

Como se mencionó anteriormente en esta sección, la función $\hat{f}$ es paramétrica, es decir, depende de un conjunto finito de parámetros $\theta$. La calidad de la aproximación se obtiene mediante la optimización de dichos parámetros con el fin de minimizar una función de costo, generalmente denominada $\mathcal{L}$, la cual cuantifica la discrepancia entre las predicciones del modelo y los valores reales observados. Para cuantizar estos errores se utilizan diferentes métricas, las cuales se detallarán en la sección \ref{sec:metricas}.

La definición formal de la función de costo $\mathcal{L}$ y los métodos empleados para su optimización se presentarán más adelante en la sección \ref{sec:funcion_de_costo}.

% En primer lugar, para hallar $\hat{f}$, se debe definir el tipo de modelo a utilizar, es decir, la forma funcional de $\hat{f}$. Lo cual dependerá de la naturaleza del sistema a modelar. Existen dos principales clases de problemas de modelado: regresión y clasificación. La diferencia radica en el espacio de salida $y$. En los problemas de regresión, la variable de salida es continua, mientras que en los problemas de clasificación, la variable de salida es discreta y representa categorías o clases.
