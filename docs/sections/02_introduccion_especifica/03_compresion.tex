\section{Compresión}
\label{sec:compresion}

La compresión es el proceso que consiste en reducir el tamaño de los datos, con el objetivo de disminuir el espacio de almacenamiento requerido y el tiempo de transmisión. Es una técnica fundamental en el procesamiento digital, con aplicaciones como la compresión de imágenes (ej. JPEG, PNG) y la de audio (ej. MP3, FLAC).

Existen dos tipos principales de compresión \cite{Kavitha2016A}:

\begin{itemize}
    \item \textbf{Compresión sin pérdida (Lossless)}: Permite reconstruir los datos originales de forma exacta a partir de los datos comprimidos, sin ninguna pérdida de información.
    \item \textbf{Compresión con pérdida (Lossy)}: Sacrifica parte de la información, que se considera menos perceptible o relevante, para lograr una tasa de compresión mucho mayor. El objetivo es que la diferencia entre el dato original y el reconstruido sea mínima desde un punto de vista perceptual.
\end{itemize}

Este último concepto, el de una compresión con pérdida, es análogo a lo que se busca en la compresión de redes neuronales, donde se sacrifica precisión numérica para ganar eficiencia.
