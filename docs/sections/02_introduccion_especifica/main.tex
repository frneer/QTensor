En este capítulo se presentan los fundamentos teóricos y prácticos que sustentan el trabajo. Se comienza con una introducción al modelado de sistemas y a los principios del aprendizaje automático supervisado, utilizando la regresión lineal y la regresión logística como ejemplos introductorios. También se describe el método de optimización por descenso de gradiente.

A continuación, se detallan las métricas empleadas para evaluar tareas de regresión y clasificación. Luego se aborda el estudio de las redes neuronales, desde el perceptrón simple hasta el perceptrón multicapa, con una explicación en profundidad del algoritmo de entrenamiento basado en retropropagación.

Seguidamente se introduce el concepto de compresión, con foco en las técnicas aplicadas a redes neuronales. Dentro de estas técnicas se profundiza en la cuantización, retomando las estrategias PTQ y QAT ya presentadas. Se describe el funcionamiento de QAT, haciendo hincapié en el problema de los gradientes en funciones no diferenciables y en la solución más utilizada para este tipo de casos: el estimador \textit{Straight-Through Estimator} (STE), que permite propagar gradientes aproximados incluso cuando la función de cuantización no es diferenciable.

Finalmente, se describen los frameworks de software utilizados, \texttt{TensorFlow} y \texttt{TensorFlow Model Optimization}, y se introduce la funcionalidad de los gradientes personalizados, una herramienta clave para implementar el comportamiento de STE.
