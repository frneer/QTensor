En este capitulo de explicaran los fundamentos necesarios para comprender el trabajo realizado. Se comienza con una introducción al modelado de sistemas para establecer los principios del aprendizaje automático. Luego, se describen las redes neuronales como un modelo de aprendizaje no lineal e iterativo, detallando el algoritmo de \textbf{backpropagation}. Posteriormente, se introduce el concepto general de compresión de datos y se detallan diversas técnicas específicas para la compresión de redes neuronales, enfocándose finalmente en la cuantización. Se detalla el mecanismo de la cuantización durante el entrenamiento (\textbf{QAT}) y el rol del Straight-Through Estimator (STE).
