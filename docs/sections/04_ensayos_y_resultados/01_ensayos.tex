\section{Ensayos y pruebas}
\label{sec:ensayos_y_pruebas}

El objetivo de los ensayos realizados es mostrar un ejemplo completo de la utilización de la biblioteca \texttt{QTensor} para cuantizar un modelo de \texttt{TensorFlow}, entrenarlo y evaluar su desempeño en un conjunto de datos real.

En particular, se busco demostrar las ventajas del cuantizador flexible en cuestiones de precisión y tamaño del modelo, comparando el desempeño de modelos cuantizados con diferentes esquemas de cuantización. Como se busca una comparacion entre dos esquemas, es necesario partir de un modelo entrenado de la misma manera. Para esto se utilizo la definición de un \texttt{Pipeline} para entrenar el modelo base, y luego se cuantizo este modelo con diferentes esquemas de cuantización.

\subsection{Dataset CIFAR-10}

El conjunto de datos utilizado es el conjunto de datos CIFAR-10\cite{krizhevsky2009learning}, que consiste en 60.000 imágenes de 32x32 píxeles en color, divididas en 10 clases diferentes (avión, automóvil, pájaro, gato, ciervo, perro, rana, caballo, barco y camión). El conjunto de datos está dividido en 50.000 imágenes de entrenamiento y 10.000 imágenes de prueba.

\subsection{Esquemas de cuantización}
No se hizo una busqueda exhaustiva de esquemas de cuantización, sino que se seleccionaron dos esquemas que se consideraron representativos de las diferentes opciones disponibles en la biblioteca \texttt{QTensor}.

Los \textit{biases} se cuantizaron todos con el mismo esquema, de cuantizador uniforme simétrico, de 8 bits.

Las activaciones se cuantizaron con un cuantizador uniforme asimétrico de 16 bits, las activaciones son los valores que más varían el desempeño del modelo, por lo que se decidió utilizar un esquema de cuantización más preciso para estas.

La cuantización de los pesos se hizo con dos cuantizadores diferentes, para comparar el desempeño de estos. Un grupo de modelos se cuantizo con un cuantizador uniforme simétrico con una matriz de bits {2, 4, 6 ...} y otro grupo de modelos se cuantizo con un cuantizador flexible simétrico con una matriz de bits {2, 4, 6 ...}.
