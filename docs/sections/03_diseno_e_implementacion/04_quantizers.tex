\subsection{Implementación de los cuantizadores (módulo \texttt{quantizers})}
\label{sec:implementation_quantizers}

\subsubsection{Clase \texttt{Quantizer}}
La interfaz de \texttt{TFMOT} \texttt{Quantizer} \cite{tensorflow_quantizer_api} define las operaciones matemáticas que transforman tensores durante la cuantización, mediante dos métodos:

\begin{enumerate}
    \item \texttt{build}: construye las variable necesarias para el algoritmo de cuantización, en caso de ser necesario.
    \item \texttt{\_\_call\_\_}: aplica la operación de cuantización a los tensores de entrada.
\end{enumerate}

El método \texttt{build} se llama una vez que se conoce la forma de los tensores de entrada, y permite inicializar las variables de estado. El método \texttt{\_\_call\_\_} se llama cada vez que se aplica la cuantización y debe implementar su lógica. Esta operación se integra en el grafo computacional (sección \ref{sec:tensorflow_model_optimization}) para ejecutarse durante el \textit{forward pass}. Además, las operaciones realizadas deben tener definidas sus derivadas para permitir el cálculo de gradientes durante el \textit{backward pass}.

\subsubsection{Modificaciones a la clase \texttt{Quantizer}}

Para implementar cuantizadores con parámetros entrenables y gradientes personalizados, se crearon clases que heredan de \texttt{Quantizer} (de \texttt{TFMOT}), extendiendo su funcionalidad mediante modificaciones en los métodos \texttt{build} y \texttt{\_\_call\_\_}.

Con el fin de definir gradientes personalizados, se define un método adicional \texttt{quantize} decorado con \texttt{@tf.custom\_gradient} \cite{tensorflow_custom_gradient}, explicado en la sección \ref{sec:gradientes_personalizados}, donde se define la función de cuantización y su gradiente. El método \texttt{\_\_call\_\_} llama a \texttt{quantize} para aplicar la cuantización con el gradiente personalizado.

Por otro lado, para habilitar parámetros entrenables, se modificó el método \texttt{build} para declarar las variables como tensores entrenables de Keras (\texttt{tf.Variable}). Esto permite que las variables se entrenen junto con el modelo, y se actualicen durante el proceso de entrenamiento a partir de los gradientes calculados.

\paragraph{Restricciones para parámetros entrenables (submódulo \texttt{constraints})}
% \newline
Los parámetros entrenables de los cuantizadores tienen restricciones específicas que garantizan la validez matemática de las operaciones de cuantización. Por ejemplo, los niveles y umbrales de la cuantización deben mantenerse siempre ordenados, y el parámetro que define el rango $\alpha$ debe ser estrictamente positivo.

Para implementar este comportamiento se utilizó la interfaz de \texttt{Keras} \texttt{Constraint} \cite{tensorflow_keras_constraint}, la cual define operaciones de restricción que se aplican a los tensores durante el entrenamiento, como parte de su actualización. Se implementaron tres restricciones personalizadas en el módulo \texttt{constraints} \cite{qtensor_constraints}, cuyos detalles se resumen en la tabla \ref{tab:quantizer_constraints}.

\input{sections/03_diseno_e_implementacion/04_tab_constraints}

Como ejemplo, el fragmento de código \ref{code:quantizer_constraints} muestra la implementación de la restricción \texttt{PositiveConstraint}, donde se utiliza la función \texttt{tf.clip\_by\_value} \cite{tensorflow_clip_by_value} para limitar los valores del tensor entre un valor mínimo (en este caso, un valor muy pequeño positivo definido por \texttt{tf.keras.backend.epsilon()} \cite{tensorflow_epsilon_api}) y el infinito positivo. Es necesario utilizar un valor mínimo mayor a cero para evitar divisiones por cero en los cálculos posteriores y asegurar la estabilidad numérica.

  class PositiveConstraint(tf.keras.constraints.Constraint):
    def __call__(self, w):
        return tf.clip_by_value(w, tf.keras.backend.epsilon(), np.inf)
\end{lstlisting}

\paragraph{Inicialización y regularización}

Además de la definición de gradientes personalizados y parámetros entrenables, los cuantizadores implementados exponen mecanismos para controlar la inicialización y regularización de dichos parámetros.

Para ello, los parámetros entrenables se agregan a la capa mediante el método \texttt{add\_weight} \cite{tensorflow_add_weight_api}, el cual permite especificar tanto el inicializador como el regularizador. En consecuencia, el usuario puede elegir cómo inicializar los parámetros mediante el argumento \texttt{initializer} \cite{tensorflow_initializers_api}, así como también definir estrategias de regularización a través del argumento \texttt{regularizer} \cite{tensorflow_regularizers_api}.

\subsubsection{Implementación del cuantizador uniforme}

El fragmento de código \ref{code:uniform_quantizer_full} muestra la implementación completa de la función de cuantización uniforme y sus gradientes a manera ilustrativa, la implementación completa se encuentra en \cite{qtensor_uniform_quantizer}.

La función de cuantización uniforme, definida en la ecuación \eqref{eq:uniform_quantizer} (sección \ref{sec:uniform}), limita primero los valores de entrada al rango definido por los niveles mínimo y máximo mediante la función \texttt{tf.clip\_by\_value} \cite{tensorflow_clip_by_value}, y luego aplica la cuantización mediante la operación de piso (\texttt{tf.math.floor} \cite{tensorflow_math_floor}).

Para implementar los gradientes definidos en la sección \ref{sec:uniform_quantizer_gradient}, se decora la función de cuantización \texttt{quantize} con \texttt{@tf.custom\_gradient} (explicado en la sección \ref{sec:gradientes_personalizados}), la cual devuelve el valor cuantizado \texttt{q} y la función de gradiente personalizada \texttt{grad}, la cual debe definir dos gradientes: uno con respecto a la entrada $x$ y otro con respecto al parámetro $\alpha$.

En particular, \texttt{grad} define el gradiente de la función de cuantización uniforme con respecto a la entrada $x$, $\frac{\partial q_{u}}{\partial x}$, definida en \eqref{eq:uniform_quantizer_ste_signed}, utilizando la función \texttt{tf.where} \cite{tensorflow_where} descrita en la sección \ref{sec:tensorflow_graph} para aplicar el STE. Esta retorna el gradiente acumulado (\texttt{upstream}) cuando el valor de entrada $x$ se encuentra dentro del rango definido por los niveles, y cero en caso contrario. El uso de \texttt{tf.where} es necesario para operar de manera segura en el contexto del grafo computacional de TensorFlow.

Por otra parte, el gradiente con respecto al parámetro $\alpha$, $\frac{\partial q_{u}}{\partial \alpha}$, definido en \eqref{eq:uniform_quantizer_dq_dalpha}, se calcula de manera diferente. A diferencia del caso anterior, donde existe un gradiente para cada elemento de $x$, aquí $\alpha$ es un único escalar que afecta a todos los elementos del tensor de entrada. Por lo tanto, se calcula un gradiente para cada elemento $x_i$ con respecto a $\alpha$, y luego se suman todos estos gradientes para obtener el gradiente total mediante \texttt{tf.reduce\_sum} \cite{tensorflow_reduce_sum}.

\begin{lstlisting}[language=Python,label=code:uniform_quantizer_full,caption=Implementación completa del cuantizador uniforme con gradientes personalizados.]
@tf.custom_gradient
def quantize(x, alpha):
  clipped_x = tf.clip_by_value(x, self.levels[0], self.levels[-1])
  q = self.delta() * tf.math.floor(clipped_x / self.delta())

  def grad(upstream):
    dq_dx = tf.where(
        tf.logical_and(
            tf.greater_equal(x, levels[0]),
            tf.less_equal(x, levels[-1]),
        ),
        upstream,
        tf.zeros_like(x),
    )

    dq_dalpha = tf.reduce_sum(q / alpha * upstream)

    return dq_dx, dq_dalpha

  return q, grad
\end{lstlisting}

\subsubsection{Implementación del cuantizador flexible}

El fragmento de código \ref{code:flexible_quantizer_full} muestra la implementación completa de la función de cuantización flexible y sus gradientes a manera ilustrativa, la implementación completa se encuentra en \cite{qtensor_flexible_quantizer}.

La implementación de la función de cuantización flexible definida en \eqref{eq:flexible_quantizer} cuantiza primero los niveles utilizando el cuantizador uniforme definido anteriormente, y luego cuantiza la entrada $x$ asignándole el nivel correspondiente según los umbrales definidos mediante la función \texttt{tf.where}.

Para implementar los gradientes definidos en la sección \ref{sec:flexible_quantizer_gradient}, se decora la función de cuantización \texttt{quantize} con \texttt{@tf.custom\_gradient} y se define la función de gradiente personalizada \texttt{grad}, la cual debe definir cuatro gradientes: uno con respecto a la entrada $x$, otro con respecto al parámetro $\alpha$, otro con respecto a los niveles $l$ y otro con respecto a los umbrales $t$.

El gradiente de la función de cuantización flexible con respecto a la entrada $x$, $\frac{\partial q_{f}}{\partial x}$, es idéntico al del cuantizador uniforme al ser un STE. Lo mismo ocurre con el gradiente con respecto a $\alpha$, $\frac{\partial q_{f}}{\partial \alpha}$.

Por otro lado, el gradiente con respecto a los niveles $l$, $\frac{\partial q_{f}}{\partial l}$, descrito en \eqref{eq:flexible_quantizer_dq_dl}, presenta una situación análoga al caso de $\alpha$: la dimensión de la entrada $x$ (un tensor) no corresponde con la dimensión de los niveles $l$ (un vector). Por lo tanto, se debe acumular el gradiente de todos los valores $x_j$ que son cuantizados al mismo nivel $l_i$, es decir, todos aquellos que caen dentro del intervalo definido por los umbrales $t_i$ y $t_{i+1}$. Para esto, se utiliza \texttt{tf.searchsorted} \cite{tensorflow_searchsorted} para encontrar el índice del nivel correspondiente a cada valor cuantizado, luego \texttt{tf.one\_hot} \cite{tensorflow_one_hot} para crear una matriz one-hot \cite{one_hot_encoding} con estos índices, y finalmente \texttt{tf.matmul} \cite{tensorflow_matmul} para multiplicar la matriz one-hot transpuesta por el gradiente acumulado (\texttt{upstream}). Nuevamente, se utilizan estas operaciones de TensorFlow para operar de manera segura en el contexto del grafo computacional, como fue explicado en la sección \ref{sec:tensorflow_graph}.

De manera similar, el gradiente con respecto a los umbrales $t$, $\frac{\partial q_{f}}{\partial t}$, descrito en \eqref{eq:flexible_quantizer_dq_dt}, también requiere acumulación debido a la discrepancia dimensional entre $x$ y $t$. En este caso, cada umbral $t_i$ afecta a un subconjunto específico de valores de entrada: aquellos que caen dentro del rango definido por los umbrales adyacentes $t_{i-1}$ y $t_{i+1}$. Por lo tanto, se calcula un gradiente para cada valor $x_j$ en ese rango con respecto a $t_i$, y luego se suman. Para esto, se utiliza \texttt{tf.where} \cite{tensorflow_where} para crear una máscara que seleccione solo los valores relevantes, luego \texttt{tf.reduce\_sum} \cite{tensorflow_reduce_sum} para sumar sus gradientes, y finalmente \texttt{tf.tensor\_scatter\_nd\_update} \cite{tensorflow_tensor_scatter_nd_update} para actualizar el valor del gradiente correspondiente al umbral $t_i$.

\begin{lstlisting}[language=Python,label=code:flexible_quantizer_full,caption=Implementación completa del cuantizador flexible con gradientes personalizados.]
def quantize(x, alpha, levels, thresholds):
  # Cuantizar los niveles usando cuantizacion uniforme
  qlevels = uniform_quantizer(levels)

  # Cuantizar la entrada
  q = tf.zeros_like(x)
  for i in range(thresholds.shape[0] - 1):
      q = tf.where(
          tf.logical_and(
              tf.greater_equal(x, thresholds[i]),
              tf.less_equal(x, thresholds[i + 1]),
          ),
          qlevels[i],
          q,
      )

  def grad(upstream):
    dq_dx = tf.where(...)  # Igual que uniform quantizer
    dq_dalpha = tf.reduce_sum(q / alpha * upstream)

    # dq_dlevel
    bin_indices = tf.searchsorted(qlevels, tf.reshape(q, (-1,)), side="left")
    q_one_hot = tf.one_hot(bin_indices, depth=qlevels.shape[0])
    dq_dlevel = tf.matmul(
        tf.transpose(q_one_hot), tf.reshape(upstream, (-1, 1))
    )
    dq_dlevel = tf.reshape(dq_dlevel, (-1,))

    # dq_dthresholds
    dq_dthresholds = tf.zeros_like(thresholds)
    for i in range(1, thresholds.shape[0] - 1):
        delta_y = qlevels[i - 1] - qlevels[i]
        delta_x = thresholds[i + 1] - thresholds[i - 1]

        masked_upstream = tf.where(
            tf.logical_and(
                tf.greater_equal(x, thresholds[i - 1]),
                tf.less_equal(x, thresholds[i + 1]),
            ),
            upstream,
            tf.zeros_like(x),
        )

        update_value = delta_y / delta_x * tf.reduce_sum(masked_upstream)
        dq_dthresholds = tf.tensor_scatter_nd_update(
            dq_dthresholds, indices=[[i]], updates=[update_value]
        )

    return dq_dx, dq_dalpha, dq_dlevel, dq_dthresholds

  return q, grad
\end{lstlisting}
